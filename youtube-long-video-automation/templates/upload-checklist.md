## Video check

- [ ] Video is 16:9 horizontal landscape, 1280x720, verified with ffprobe: width 1280, height 720
- [ ] Total length 3-5 minutes (18-30 scenes, in script order)
- [ ] All 18-30 scenes present, in the right order, no scene missing or duplicated
- [ ] 2-second pause before each sound reveal is present
- [ ] Finale loops cleanly back to the hook
- [ ] Audio / voiceover matches the script, one speaker per line
- [ ] No burned-in text, no dialogue bubble, no off-model character in any scene
- [ ] Watched the finished video start to finish (not just the first seconds)
